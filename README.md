# RETURN TO CLASSIC SNAKE GAME! 2013

個人制作 - 年賀コンテンツとして制作されたブラウザ向けスネークゲーム（2013年版）

## 概要

2013年の年賀コンテンツとして制作された 3D エフェクト付きのブラウザ向けスネークゲームです。クラシックなスネークゲームに 3D 視覚効果を組み合わせ、新年の演出として「2013」の文字をパーティクルで表現する特別な仕様になっています。

## 主要機能

### ゲーム機能
- クラシックなスネークゲームのルール
- キーボード（矢印キー）での操作
- 餌を食べてスコアアップ & 蛇が成長
- 壁や自分の体にぶつかるとゲームオーバー

### 3D視覚効果
- Sprite3D.js による 3D 回転エフェクト
- ブロック単位での立体的な表示
- 滑らかなアニメーション演出

### 年賀演出
- ゲーム開始前に「2013」の文字をパーティクルで表現
- 段階的なアニメーション演出
- 新年らしい緑基調の配色

### モバイル対応
- **スマートフォン向け操作UI** - Claude Code で追加実装
- 十字キーパッド（上下左右ボタン）による直感的な操作
- 大型のSTARTボタンでゲーム開始・リスタート
- レスポンシブデザインで画面サイズに自動調整

## 操作方法

### デスクトップ
- **矢印キー**: 蛇の移動方向を制御
- **スペースキー**: ゲーム開始/リスタート

### スマートフォン
- **十字キーパッド**: 蛇の移動方向を制御（上下左右ボタン）
- **STARTボタン**: ゲーム開始/リスタート

### 共通
- **目標**: 餌（赤いブロック）を食べてスコアを上げる
- **注意**: 壁や自分の体に衝突するとゲームオーバー

## 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript (ES5)
- **3D エフェクト**: Sprite3D.js
- **アニメーション**: EaselJS 0.5.0, TweenJS 0.3.0
- **ユーティリティ**: jQuery 1.6.4, jquery.color.js
- **レンダリング**: HTML5 Canvas + CSS3 Transform

## セットアップ

### 必要環境
- モダンな Web ブラウザ（Chrome, Firefox, Safari 推奨）
- JavaScript 有効

## 実装の特徴

### ゲームロジック
- チュートリアル（http://www.strille.net/tutorials/snake/index.php）を参考に実装
- 20x20のグリッドベースでのゲーム進行

### 年賀演出システム
1. **Notice フェーズ**: 開始時の注意書き表示
2. **Year フェーズ**: 「2013」文字をパーティクルで段階的に表示  
3. **Wall フェーズ**: ゲームフィールドの3D回転演出
4. **Text フェーズ**: ゲームタイトルの表示
5. **Game フェーズ**: 実際のゲームプレイ

### 3D エフェクト
- CSS3 Transform を使用した3D空間での回転
- 各ブロックを個別の DOM 要素として管理
- 滑らかなアニメーション遷移

### モバイル対応システム（Claude Code 実装）
- **デバイス自動検出**: User-Agent と画面幅による判定
- **タッチ操作**: jQuery 1.6.4 互換の `.bind()` メソッドでイベント処理
- **レスポンシブUI**: メディアクエリによる画面サイズ別レイアウト調整
- **視覚的フィードバック**: ボタン押下時のアニメーション効果
- **ゲーム配色統合**: 既存のゲーム要素と調和する配色設計

## 動作環境

### デスクトップ
- **対応ブラウザ**: Chrome, Firefox, Safari（当時のモダンブラウザ）
- **画面解像度**: 1024x768 以上推奨
- **JavaScript**: ECMAScript 5 対応

### モバイル（Claude Code 追加対応）
- **対応デバイス**: スマートフォン、タブレット
- **対応ブラウザ**: モバイル版 Chrome, Safari, Firefox
- **画面幅**: 768px 以下で自動的にモバイルUI表示
- **タッチ操作**: touchstart/touchend イベント対応
